# Artha
> Premium Personal Finance for Indian Investors

Artha is a high-end, futuristic financial operating system tailored for the modern Indian investor. It empowers you to track your net worth across diverse asset classes, analyze mutual fund performance with deep insights, optimize your portfolio for sector concentration, and make data-driven financial decisions using advanced simulators.

## ✨ Key Features
- **Net Worth Tracker:** Real-time visibility into your total wealth, debt, and growth trends.
- **Mutual Fund Intelligence:** Research, compare, and simulate funds to build a historically resilient portfolio.
- **Portfolio Analyzer:** Discover hidden risks, sector concentrations, and optimization opportunities.
- **Financial Simulators:** Goal-based SIP planning and EMI calculators for precision planning.
- **AI Financial Advisor:** Context-aware investment guidance powered by intelligent financial modeling.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Baidurja-200/Artha.git
   cd Artha
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
